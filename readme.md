# 📝 TO-DO App

A beautiful, modern, and fully functional To-Do List application designed . Built to help you stay organized and boost your daily productivity with smooth animations and an intuitive user experience.

Live Demo : https://vishalrathod28.vercel.app/

Updated app :

## ✨ Features

- **Add Tasks:** Quickly write down what you need to do throughout the day.
- **Edit Tasks:** Made a typo? Easily edit existing tasks in-line with a single click.
- **Delete Tasks:** Remove tasks you no longer need.
- **Mark as Complete:** Check off tasks as you finish them (includes smooth strikethrough styling).
- **Beautiful UI:** Modern Neumorphic design with soft shadows and inset input fields.
- **Smooth Animations:** Tasks gently slide and fade into the list when added.
- **Fully Responsive:** Looks great on desktops, tablets, and mobile phones.
- **No Page Reloads:** State is managed entirely with Vanilla JavaScript for a seamless, app-like feel.

## 🛠️ Tech Stack

This project was built using lightweight, modern web technologies:

- **HTML5:** For the semantic structure of the app.
- **Tailwind CSS:** (via CDN) Used for all the styling, layout, and neumorphic shadow utilities.
- **Vanilla JavaScript:** Handles the application logic, DOM manipulation, and state management without the need for heavy frameworks.

## 🚀 Getting Started

Since this project uses Vanilla JS and Tailwind via CDN, there is no complex build process or installation required! 

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge).
- A code editor (like VS Code) if you want to modify the code.
